CD-SYS-001 · 1.0

Operating model: agentic engineering

The Brain (codename Conductor) is the platform for a controlled engineering methodology. Unstructured AI-assisted development (“vibe coding”) does not scale past one person and cannot be trusted with sensitive data. The Brain replaces it with agentic engineering: business-unit leads specify and accept the work, AI agents execute it in sandboxes against a central context store, and a routing policy decides which data may reach frontier models and which stays on local compute. It is also the processing engine for Site Capture (W-3 to W-6).

Slot and connector usage on the TURIND8X-2T. The GPU goes in a full x16 slot that shares no lanes: slot 0, 2, 4 or 6. Slot 1 shares lanes with one MCIO port and one M.2; slot 7 (x8) shares with two MCIO ports. Memory population follows the board manual's 4-DIMM rule.

CD-SYS-001 · 8.0

Security

Conductor holds client facility data. Controls below are targets for the first client job; none is claimed as certified.

Management plane

  1. BMC/IPMI on a dedicated management VLAN, never on the user LAN
  2. Change BMC default credentials at first boot
  3. Update BMC and BIOS firmware before the first client job

Data at rest

  1. Full-disk encryption on data volumes (target)
  2. Encrypted NAS shares and offsite copy
  3. Deletion on contract end, logged

Access

  1. Named user accounts, key-only SSH
  2. Host firewall; only required services exposed
  3. No client data in cloud API prompts without client approval

Chain of custody

  1. Field manifest with SHA-256 per file
  2. Verify on ingest; log operator and time
  3. QA report lists the dataset hashes

Upgrades are ordered by the constraint they remove. The Site Capture scanning workload moves the NAS ahead of the first client job and gives the GPU upgrade a concrete trigger.

Confirm 3× vs 2× EPS (CD-R-01). Order Baseline within the price guarantee.

Build + burn-in

Verify CD-REQ-003, 009, 010, 011. Record wall power and thermals.

G2 · before first job

NAS + pilot processing

Install NAS (CD-REQ-006). Process Site Capture pilot-day data end-to-end; set CD-REQ-013.

Memory, GPU, power

Final build · decided Nov 17, 2026

We're building Option A: the EPYC 9175F in the Antec 900. The Threadripper PRO upgrade (Option B) is not being built.

The machine is an orchestration hub. It runs many agent sessions at once, each calling cloud models (Claude, OpenAI) and local tools: MCP servers, headless browsers, vector search and containers. The RTX 5070 Ti serves small local models for routing, embeddings and fallback, so not every call leaves the building.

  • CPU + board + memory: AMD EPYC 9175F (16 cores, 512 MB L3) + ASRock Rack TURIND8X-2T + 128 GB Kingston FURY Renegade Pro RDIMM (4×32), Micro Center bundle
  • GPU: ASUS ProArt RTX 5070 Ti OC 16 GB
  • Cooler: SilverStone XE360-SP5, top-mounted as exhaust
  • Power: Super Flower Leadex VII Platinum PRO 1200 W
  • Case: Antec 900, with 6 fans included
  • Storage: 2× Kioxia CD6-R 7.68 TB U.3 (Amazon, the Expertly.Ai pick) + 2× MCIO→U.2 cables

Upgrade path: 1) memory first: 4 more identical RDIMMs gives 256 GB on all 8 channels and twice the bandwidth; 2) GPU memory second: an RTX PRO 5000 48 GB or a second card (4 full x16 slots free); 3) a bigger PSU only when a second 300 W+ GPU goes in. Why A over B →
